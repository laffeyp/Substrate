# Archive

Prior drafts and ancillary review documents from the Substrate spec
corpus.

## Convention

When a new draft of any spec is cut, the previous draft is moved here
before being overwritten. Naming:

- Kernel spec: `horizon_substrate_v<N>.md` (e.g. `horizon_substrate_v14.md`)
- Product spec: `product_spec_DRAFT<N>.md`
- Technical spec: `technical_spec_DRAFT<N>.md`
- Design spec: `design_spec_DRAFT<N>.md`
- Reviews/critiques: `<spec>_DRAFT<N>_<kind>.md` (e.g. `product_spec_DRAFT1_critique.md`)

## What's here

- **`product_spec_DRAFT1_critique.md`** — critique notes against the
  first draft of the product spec. The substantive findings were
  incorporated into DRAFT 2 of the product spec (and survive in the
  current DRAFT 7). Kept for reference because the issues-by-
  destination list at the end is a useful artifact for anyone
  tracking how the product spec evolved.

## What's NOT here

Earlier draft files of the four current specs. Each spec has only
ever existed as a single file; revisions were made in place. Drafts
1 through (N-1) of any spec are represented only in that spec's
Document History section and in this conversation's transcript. From
this point forward, prior drafts will land here as part of the
draft-cutting discipline.
