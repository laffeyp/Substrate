# Committed run records — deterministic, CI-mode

These are **deterministic, CI-mode** run records for the reference topologies
R-1/R-2/R-3, produced with the stand-in Producers (no LLM), so a fresh checkout can
read them back with no Ollama and no network:

```
substrate tail    records/r2
substrate inspect records/r2 --seq 14
substrate replay  records/r2 --level 2
```

They are regenerated by `scripts/gen_walkthrough_records.py`.

These are **not** real-model outputs. The illustrative transcripts from real local
Ollama runs live in the walkthroughs doc one level up (`../README.md`); reproduce
them yourself with the `[openai-compat]` extra. The records here are the durable,
replayable artifact you can verify by hash; the transcripts are illustration.
